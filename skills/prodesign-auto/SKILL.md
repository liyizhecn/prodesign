# prodesign-auto — 全流程驱动（∞）

> 路径约定：下文 `$SKILLS` 指本套件的安装根目录——项目级 `.claude/skills`（优先）或全局 `~/.claude/skills`，按实际存在解析。


按顺序驱动全部阶段。**每个阶段必须读取并遵循对应子命令的 SKILL.md**（`$SKILLS/prodesign-<阶段>/SKILL.md`），本文件只定义编排与停点。

## 编排

```
0 new（如无工作区）→ ① req → ② research → ③ prd → ④ review → ⑤ proto → validate --strict → ⏹ archive
```

- 开始前运行 `status` 判断当前处于哪个阶段，**从未完成的阶段续跑**，不重做已完成阶段。
- 每个阶段结束运行 `validate <slug>` 自查，错误清零才进入下一阶段。
- 阶段间用一句话向用户汇报："阶段②完成：3 个设计题、L×7 条教训，进入 PRD。"

## 必须停下等用户的点（不可跳过）

| 停点 | 内容 |
|---|---|
| 阶段① Q 拍板 | 待确认项逐条请用户定论（AskUserQuestion），AI 不得代拍 |
| 阶段② 冲突上报 | 调研结论与 Q 定论冲突时请用户再拍板 |
| 阶段④ 取舍补强 | 涉及取舍的规格补强请用户拍板；收敛后汇报遗留风险 |
| ⏹ 归档确认 | 展示 changelog 摘要，用户确认后才执行 archive |

其余环节自主推进，不要为可自行决定的细节打断用户。

## 长会话保护

- 每完成一个阶段，阶段产物已落盘，上下文压缩后从文件恢复状态（`status` + 读工作区文件），不要凭记忆续写。
- 会话过长时优先保证 changelog/handoff 落盘——它们是跨会话的生命线。
