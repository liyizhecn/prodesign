# prodesign 内容规范（Content 层：数据格式与文案）

> 母本：Ant Design 文案与数据格式规范 + Polaris/GOV.UK 内容准则精神，按 ToB 中后台裁剪。
> 界面上的每个字和每个数都有规则；产品级术语以 project.md 术语表为唯一权威。

## 1. 数据格式

| 类型 | 规则 | 示例 |
|---|---|---|
| 时间（表格/详情） | 绝对时间 `YYYY-MM-DD HH:mm`，秒仅在审计/日志类展示；mono 字体 | 2026-08-12 10:00 |
| 时间（动态流） | 24h 内可用相对时间，hover title 给绝对时间 | 3 分钟前 |
| 时长 | 自适应单位，保留一位小数；毫秒场景整数 | 1.2s / 353ms |
| 数字 | ≥1000 千分位分隔；表格数字右对齐 | 47,600 |
| 金额 | 货币符号全局统一（project.md 定）；两位小数；量纲写进列头 | ¥1,234.56 / 单价（每 1M token） |
| 百分比 | 一位小数；进度类整数 | 99.2% / 80% |
| **空值** | 统一用 `—`（em dash），不留白、不写 null/0；空值≠零值 | sessionID 未传显 `—` |
| ID / 密钥 | mono 字体；密钥默认打码显前后 4 位，明文查看走独立操作 | vk-77ef…a3c1 |
| 邮箱脱敏 | 本地部分前 2 字符 + `***` | zh***@corp.com |
| 手机脱敏 | 前 3 后 4 | 138****5678 |
| 非 token 量纲 | 不与 token 混列；量纲写进列头或单元格后缀 | 12 张（dall-e-3） |

## 2. 文案五原则

1. **事实优先**：先说发生了什么，再说影响；不渲染情绪（"SMTP 连接失败"，不是"糟糕！出错了"）。
2. **错误三要素**：发生了什么 + 为什么/关键参数 + 怎么办。"SMTP 连接失败——connection refused (mail.corp.local:465)。请检查主机与端口配置。"
3. **主语明确**：谁做的、对什么对象；系统行为主语是"系统"（"系统已自动切换至备用模型"）。
4. **不携带敏感内容**：通知、日志摘要、错误信息不回显命中原文/密码/密钥明文；引用对象用 ID + 名称快照。
5. **一物一名**：同一概念全产品唯一命名（project.md 术语表权威）；状态词、按钮动词从本规范词表取，不造同义词。

## 3. 按钮动词表

| 场景 | 用词 | 禁用 |
|---|---|---|
| 创建 | 新建 / 签发 / 添加（子项） | 增加、创建（口语不一） |
| 修改 | 编辑（进入态）/ 保存（提交态） | 修改、确定 |
| 删除 | 删除（确认弹窗主按钮仍用"删除"） | 确定、移除（除非是"从列表移除不删实体"） |
| 启停 | 启用 / 停用（可逆）；失效（不可逆终态） | 禁用与停用混用 |
| 确认类 | 用具体动词复述操作："覆盖原策略" | 确定、OK、是 |
| 取消 | 取消（次按钮，永远在主按钮左侧） | 关闭（仅用于纯查看抽屉） |

## 4. 状态词表（成对/成组）

- 生命周期：`未启用 → 已启用 ⇄ 已停用 → 已失效（终态）`；`已过期` 单独用于时间到期。
- 任务态：`等待中 → 进行中 → 已完成 / 已失败`；重试中标注次数（"重试中 2/3"）。
- 处置结果（安全类）：`告警放行 / 脱敏放行 / 拦截阻断`。
- 运营状态：`待处理 / 已确认 / 误报 / 已忽略`（误报=否定命中有效性；已忽略=承认有效但不处理）。
- 健康四态：`正常 / 降级 / 异常 / 未知`（unknown 是诚实的第四态，不并入异常）。
- 成对事件命名：`xxx_开始/xxx_结束`、`熔断_打开/熔断_恢复`——事件流水中可配对。

## 5. 提示与通知文案

| 载体 | 规则 |
|---|---|
| Toast | ≤14 字结论（"已保存"/"测试消息已送达"）；失败不用 Toast，用就地错误或提示条 |
| 提示条 alert | info=口径说明；warning=降级/失效标注；error=三要素；success=带对象名的结果 |
| 确认弹窗 | 标题问句（"确认删除该条目？"）+ 正文后果说明 + 审计告知句（危险操作必带） |
| 空态 | 一句话说明 + 出路（按钮或文档指引），见 patterns.md 空态三分 |
| 通知推送 | 标题=事件结论；正文=定位串（对象×方式×周期×类型）+ 回跳链接；不携带命中内容 |

## 6. 无障碍基线（低成本项）

- 对比度（WCAG AA，**validator 自动计算**）：正文类 token（--text-1/--text-2）对背景 ≥ 4.5:1；辅助文字/大字/组件（--text-3、按钮反白）≥ 3:1。
- 颜色不作为唯一信号：状态点旁必有文字；图表色阶差异辅以标签。
- 交互元素可聚焦：自定义控件（开关等）用 button 实现并带 aria-label（骨架已示范）。
