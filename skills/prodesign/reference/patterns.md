# prodesign 页型与交互模式规范（Patterns 层）

> 母本：Ant Design 设计模式（列表页/详情页/表单页规范），按本工作流裁剪。
> ToB 后台页面只有五种页型。每个原型页必须**声明页型**并遵循该页型的标准结构——页面结构不再自由发挥。

## 0. 页型声明（机械校验锚点）

每页 `<head>` 内声明：`<meta name="page-type" content="list|detail|form|dashboard|result">`。
复合页取**主页型**（如"列表 + 详情抽屉"声明 list）。骨架基座与菜单模板声明 `skeleton`（豁免页型检查）。
校验器按声明检查该页型的必备元素（见各节「校验点」）。

## 1. 列表页（list）—— 后台最高频页型

**定位**：查看和处理大量条目；导航至详情；筛选、对比、新增、批量操作、下钻。

**标准区块顺序**（自上而下）：
1. 页头：标题 + 一句话说明（可选统计卡行 `.stat-row`）
2. 筛选区：搜索框 + 维度下拉（`.table-toolbar`；≥5 个筛选维度时折叠为展开式筛选面板）
3. 工具栏：主操作按钮（新建等）居右；批量操作按钮在有勾选时出现
4. 表格：勾选列 → ID（mono）→ 名称 → 业务列 → 状态/级别（标签/状态点）→ 时间（mono）→ 操作列（文字按钮，≤3 个，更多收折叠）
5. 分页（`.pagination`）

**规则**：行内操作用 `.btn-text btn-sm`；状态用 `.dot-*` + 文字、级别用 `.tag-*`；行可点击进详情时整行 hover；删除/危险操作必须走确认弹窗（含审计告知句）；空态给引导按钮；`?focus=` 深链定位高亮必须支持。

**校验点**：`.table-toolbar`、`.table`、`.pagination` 存在。

## 2. 详情页（detail）

**定位**：展示单个对象的完整信息，信息浏览为主，就地发起编辑。

**标准区块顺序**：
1. 详情头：对象名 + ID（mono）+ 状态标签 + 主操作按钮组（编辑/停用/删除）
2. 基础信息：描述列表（`.desc`，两列网格）
3. 分组内容：多块信息用 Tab（`.tabs`）或多卡片（`.card`）分组；关联对象列表（如"该策略绑定的 vkey"）作为子表格
4. 时间线/历史记录（如有）：倒序，成对事件对齐显示

**规则**：详情优先用抽屉承载（列表页 → 右侧抽屉），独立详情页仅用于信息量大或需要分享 URL 的对象；关联对象可点击跳转（深链）；已删除的关联对象显示快照 + 失效标注，不显示死链接。

**校验点**：`.desc` 存在。

## 3. 表单页（form）

**定位**：信息录入与配置；确保按要求提交或引导完成设置。

**标准结构**：
1. 承载形态优先级：**抽屉**（单对象增改，`.drawer`）→ 弹窗（≤3 字段的轻量输入）→ 独立页/分步向导（跨多实体的复杂流程）
2. 字段顺序：必填在前；相关字段分组（组间距离 > 组内）；每字段 label + 控件 + 帮助文案（`.form-help`）
3. 校验：失焦即校验，错误就地显示（`.form-error`），提交时聚焦第一个错误；错误文案三要素（见 content-spec）
4. 底部操作：取消居左、主按钮居右；主按钮文字用具体动词（"保存"/"签发"，不用"确定"）

**规则**：必填标 `.req` 星号；创建后不可改的字段在帮助文案声明；编辑不回显密码类字段（走独立"重置"流程）；表单未保存关闭时如有改动需确认。

**校验点**：`.form-item` 存在。

## 4. 仪表盘页（dashboard）

**定位**：态势总览与下钻入口；回答"现在怎么样"。

**标准区块顺序**：
1. 统计卡行（`.stat-row`）：4±1 个核心指标，异常值用语义色（`.stat-value.danger`）
2. 趋势/分布图表区：色阶只用 `--chart-*` 令牌；每图有标题与图例；空数据显示空态而非空白图
3. 排行/明细区：Top-N 列表或紧凑表格，可下钻（深链到列表页带筛选参数）

**规则**：数值口径与来源页一致（汇总恒等，校验器可断言）；时间范围选择器全局作用于本页；刷新语义明确（自动/手动）。

**校验点**：`.stat-row` 存在。

## 5. 异常与结果页（result）

**定位**：流程终态反馈（成功/失败）与系统异常（403/404/500、维护态）。

**标准结构**：居中布局（`.empty` 变体）——图标 + 一句话结论 + 原因说明 + 出路按钮（返回/重试/去处理）。

**规则**：失败必须给原因和下一步出路，不允许只说"操作失败"；403 区分"无权限"与"登录过期"；维护态说明预计恢复时间。

**校验点**：`.empty` 存在。

## 6. 通用交互模式（跨页型）

| 模式 | 规则 |
|---|---|
| 危险操作确认 | 确认弹窗三件套：后果说明 + 审计告知句（"此操作将被审计记录。"）+ 危险色主按钮；不可逆操作要求输入对象名二次确认 |
| 引用保护 | 被引用对象禁删，错误提示列出引用方（可点击跳转）；弱引用对象可删但引用处失效标注 |
| 批量操作 | 勾选后工具栏出现批量按钮 + 已选计数；批量结果反馈成功/失败分开计数 |
| 空态 | 三种空态区分：无数据（给新建引导）、筛选无结果（给清空筛选）、无权限（说明找谁开通） |
| 加载态 | 列表用骨架屏（`.skeleton-line`），操作用按钮 loading；超 3 秒给进度或提示 |
| 状态流转 | 状态机对象的操作按钮跟随状态（已启用→显示"停用"）；流转成对事件在历史记录中配对显示 |
| 深链溯源 | 跨页跳转带 `?focus=<ID>`，目标页定位并高亮；引用展示处尽量可点击 |
